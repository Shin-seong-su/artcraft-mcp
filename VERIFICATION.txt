통과한 검사

- 최종 ZIP을 한글·공백 경로에 추출하고 분리된 HOME에서 설치.
- PATH에 Node.js가 없는 상태에서 전용 Node.js 설치.
- 공식 Node.js 및 CLI 다운로드 체크섬 확인. 재검사에서는 공식 다운로드 압축파일만 재사용하고 설정·의존성·플러그인은 새로 설치.
- VectorCraft, FigCraft, PDFCraft, CADCraft, EffectCraft, PhotoCraft의 실제 CLI Headless 연결.
- MCP 11개 도구 노출, PhotoCraft 생성 규칙 2.1 및 앱 가이드 조회.
- PhotoCraft 64×48 테스트 문서 생성·PNG 저장·이미지 크기 확인.
- 기존 개인 마켓플레이스 항목 보존.
- 실제 Codex CLI에서 로컬 플러그인 등록/설치 인식. ChatGPT GUI 검증과 구분.
- 공식 tunnel-client v0.0.18 다운로드 검증 및 실제 init 명령으로 설정 생성.
- 로그인 서비스 plist 형식 검사. 테스트용 키체인 접근은 모의 처리했으며 실제 키나 원격 연결은 사용하지 않음.
- 플러그인/MCP 공식 JSON 스키마 2개, 패키지 파일 42개 SHA-256 확인.
- 배포본에 제작자의 사용자 경로·작업 이미지·개인 터널 설정·자격증명을 포함하지 않음.

수정한 이식성 문제
- 한글·공백 설치 경로에서 서버 진입점이 실행되지 않던 URL/파일 경로 비교 오류.
- 공식 터널 ZIP 이름이 비슷한 cloudflared 런타임 패키지를 선택하던 오류.

검증 범위
같은 Apple Silicon Mac에서 HOME을 분리한 검증입니다. 별도 Mac/Intel Mac, 실제 다른 사용자 계정, 키체인 저장·로그인 자동 시작 및 ChatGPT 도구 호출까지의 최종 연결은 아직 검증하지 않았습니다. 이 검사에서 실제 AI 이미지를 새로 생성하거나 GUI 문서를 편집하지 않았습니다.
