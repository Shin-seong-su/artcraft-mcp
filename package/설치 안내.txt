ArtCraft MCP — macOS 로컬 배포 베타

이 패키지는 설치한 사람의 Mac에 있는 ArtCraft 앱/CLI를 ChatGPT에서 제어하는 연결 프로그램입니다.
ArtCraft 제작사의 공식 설치 프로그램은 아닙니다. 공개 플러그인 디렉터리에 등록된 제품도 아닙니다.

1. 설치

ZIP을 풀고 “1 설치.command”를 더블클릭합니다. 설치할 때만 터미널 창이 열립니다.
별도 Node.js/Python 설치나 관리자 암호는 필요하지 않습니다. 최초 설치에는 인터넷이 필요합니다.
공식 Node.js 22.20.0과 검증한 버전의 ArtCraft CLI 7개를 내려받고 SHA-256을 검사합니다.
PhotoCraft를 설치하면 로컬 AI 업스케일 엔진 Real-ESRGAN과 모델도 공식 배포처에서 받아 검증합니다.
사진/벡터/인터페이스/PDF/CAD/모션/스프레드시트 CLI를 준비하며 GUI 앱은 따로 설치해야 화면에서 볼 수 있습니다.

설치 위치: ~/Library/Application Support/ArtCraft MCP
기본 작업 폴더: ~/Documents/ArtCraft 작업
편집할 파일은 작업 폴더에 복사해 사용하세요. 원본 백업을 보존하고 새 이름으로 저장합니다.
PhotoCraft 기본 파일 자동화는 이 작업 폴더에 한정됩니다. AI 업스케일의 명시적 입력 파일은 Downloads에서도 읽을 수 있습니다. 다른 앱의 권한은 각 앱의 네이티브 정책을 따릅니다.
이 프로그램 전체가 운영체제 샌드박스인 것은 아닙니다.

2. 일반 ChatGPT 채팅에서 연결 (권장)

기존 제작자의 Tunnel ID나 키를 쓰는 방식이 아닙니다. 설치하는 사람 본인의 연결을 만듭니다.
Platform: https://platform.openai.com/settings/organization/tunnels
런타임 키: https://platform.openai.com/settings/organization/api-keys

터널 생성에는 Tunnels Read + Manage, 실행에는 Read + Use 권한이 필요합니다.
터널은 대상 ChatGPT 워크스페이스와 연결돼 있어야 합니다.
ChatGPT의 사용자 지정 MCP 추가 기능도 계정/워크스페이스 정책에 따라 허용돼 있어야 합니다.
이 권한이 없는 계정에서 설치만으로 사용 제한을 없애지는 못합니다.

“2 ChatGPT 연결.command” 실행 → 본인 Tunnel ID와 런타임 키 입력.
키는 화면에 표시되지 않고 macOS 키체인에 저장됩니다. ZIP/설정 JSON/로그/명령 인자에 키를 넣지 않습니다.
연결 프로그램은 이 사용자 계정의 로그인 서비스로 실행됩니다. 설정이 끝나면 터미널 창을 닫아도 됩니다.
웹 개발용 HTTP 서버를 열거나 공유기의 인바운드 포트를 개방하지 않습니다.
진단용 상태 주소는 loopback의 자동 할당 포트만 사용합니다.

ChatGPT → 플러그인 → + → 사용자 지정 MCP 서버 추가 → 연결: Tunnel → 본인 터널 선택.
도구 확인 후 새 대화에 플러그인을 추가하고 다음과 같이 요청하세요.
“ArtCraft 연결 상태를 확인해줘.”
“PhotoCraft 파일 모드에서 작업 폴더의 test.png를 열고 미리보기를 보여줘.”

최종 연결 성공은 ChatGPT에서 실제 도구 호출이 성공한 다음에 판단합니다.
설치 검사 성공이나 터널 프로세스 실행만으로 ChatGPT 연결까지 성공했다고 말하지 않습니다.
“3 연결 상태.command”로 상태를 확인하고 “4 연결 중지.command”로 이 패키지의 터널만 중지할 수 있습니다.
중지해도 작업 파일과 다른 플러그인/터널은 삭제하지 않습니다.

3. 데스크톱 로컬 플러그인 (별도 선택)

설치 프로그램은 기존 개인 마켓플레이스를 보존하면서 ArtCraft Control 항목을 추가합니다.
ChatGPT 데스크톱 앱을 본인이 편한 시점에 재시작한 후 플러그인 디렉터리의 개인 로컬 소스에서 설치/활성화합니다.
이 로컬 플러그인은 데스크톱의 로컬 실행 대화용입니다. 일반 클라우드 채팅·웹·모바일과 동일한 연결 방식이 아닙니다.
일반 채팅에서 쓸 때는 위의 개인 터널 방식을 사용하세요.
로컬 플러그인 자체에는 Tunnel ID나 런타임 키가 필요하지 않습니다.

4. 앱 제어와 생성형 채우기

Headless는 별도 파일 작업입니다. 열린 GUI 문서를 편집했다는 뜻이 아닙니다.
Live는 제어 채널로 실행한 앱에 명시적으로 연결한 상태입니다. 실패 시 Headless로 몰래 전환하지 않습니다.
기존 앱/문서를 자동 종료하지 않습니다. 이미 제어 채널 없이 실행 중이면 사용자가 저장·종료한 뒤 다시 연결합니다.
CADCraft는 이 버전에서 파일 모드만 지원합니다. 앱과 CLI 버전이 다르면 상태 응답에서 확인하고 작업 전 검증하세요.
CLI 버전은 검증된 버전으로 고정했습니다. GUI 앱 업데이트와 CLI 업데이트는 별개입니다.

PhotoCraft 생성형 채우기는 호출한 AI의 이미지 편집 도구를 사용합니다. MCP 서버에 생성 모델/API 비용이 내장된 것은 아닙니다.
PhotoCraft AI 업스케일은 별도의 로컬 엔진으로 JPG 또는 8비트 PNG를 처리해 2배·4배 또는 원래 크기의 새 PNG로 저장합니다.
4배 모델로 먼저 처리하므로 입력은 최대 4MP(중간 결과 최대 64MP)이며, 2배·원래 크기는 자동으로 축소합니다.
문서 레이어와 열린 화면을 직접 변경하지 않으며 사진·일러스트 모델을 선택할 수 있습니다. 글자와 세부 형상은 결과를 확인하세요.
원본 참조 → 서버가 만든 보존·구조 규칙 포함 프롬프트 → AI 생성 → 전체 이미지 검토 → 새 레이어 적용 순서입니다.
기본값은 아래 원본 + 위 AI 전체 결과입니다. 원본 보존은 서버가 픽셀로 검사하고, 시각적 품질은 호스트 AI가 검토합니다.
실패 검토는 적용 전에 차단하고 수정 프롬프트를 돌려줍니다. 모델의 완벽한 재현이나 자동 품질 평가는 보장하지 않습니다.

채팅 환경에 이미지 생성·편집 도구가 있어야 생성할 수 있습니다.
결과를 로컬 파일 또는 공개 HTTPS 다운로드 URL로 MCP에 넘길 수 있어야 자동 적용할 수 있습니다.
ChatGPT의 sandbox:/... 경로는 사용자 Mac의 경로가 아닙니다.
자동 전달이 안 되면 사용자가 결과 PNG를 다운로드해 작업 폴더에 저장한 뒤 그 경로를 알려주는 수동 전달도 가능합니다.

5. 업데이트·진단·제거

새 배포본의 설치를 다시 실행하면 버전별 실행 파일을 추가합니다. 기존 사용자 설정/작업 폴더는 유지합니다.
연결 중인 ChatGPT/터널은 새 실행 파일을 사용하도록 적절한 시점에 재시작하세요.
고정 CLI를 바꾸거나 새 앱 버전을 지원할 때는 별도의 호환성 검증이 필요합니다.

설치 진단: 설치 위치의 installation-report.json
실행 상태/로그: 설치 위치의 state 폴더 (개인 자료이므로 그대로 다른 사람에게 배포하지 마세요)
설정 변경: 설치 위치 config.json (workspace, appDirs, ports 등). 변경 후 연결을 재시작합니다.
제거하려면 먼저 연결 중지를 실행하고 ChatGPT에서 이 플러그인을 제거합니다.
개인 마켓플레이스에서 artcraft-control 항목만 제거한 다음 이 패키지의 설치 폴더를 Finder로 삭제할 수 있습니다.
작업 폴더는 따로 보존하세요. 키체인의 local.artcraft.chatgpt 항목은 필요할 때 키체인 접근 앱에서 제거할 수 있습니다.

이 패키지는 Apple 코드 서명/공증된 DMG가 아닙니다. 보안 경고를 자동 우회하거나 시스템 보호 설정을 끄지 않습니다.
별도의 실제 Mac/Intel Mac 및 다른 사용자의 ChatGPT 계정에서의 최종 검증은 필요합니다.
프로젝트 자체의 공개 라이선스는 아직 정하지 않았습니다. 공개 게시 전 소유자가 결정하세요.
